# M\u00e9tricas de Andamento e Crit\u00e9rios de Sucesso

## KPIs de progresso (andamento)
- Progresso de simula\u00e7\u00f5es: percentagem do total de cen\u00e1rios gerados (meta inicial: 100 cen\u00e1rios em 3 meses).
- Scripts implementados: n\u00famero de scripts para pipeline (simula\u00e7\u00e3o, pr\u00e9-processamento, HOS, extra\u00e7\u00e3o de features, avalia\u00e7\u00e3o).
- Reprodutibilidade: capacidade de rodar uma execu\u00e7\u00e3o completa via script com um comando (sim/n\u00e3o).
- Valida\u00e7\u00e3o bibliogr\u00e1fica: n\u00famero de bases/datasets da literatura comparadas.
- Produ\u00e7\u00e3o escrita: rascunho de cada cap\u00edtulo (introdu\u00e7\u00e3o, metodologia, resultados, discuss\u00e3o) — percentagem conclu\u00edda.

## KPIs t\u00e9cnicos (qualidade dos resultados)
- Detec\u00e7\u00e3o: Sensibilidade (Recall) e Especificidade para cada tipo de falha.
- Acur\u00e1cia global e ROC-AUC para classifica\u00e7\u00e3o entre condicoes.
- Limite pr\u00e1tico de detec\u00e7\u00e3o (por exemplo, comprimento de trinca m\u00ednimo detect\u00e1vel com recall > 0.8).
- Robustez: degrada\u00e7\u00e3o de desempenho com SNR decrescente (curva desempenho vs SNR).
- Tempo computacional: tempo por simula\u00e7\u00e3o e por calcula\u00e7\u00e3o HOS; requisitos de mem\u00f3ria.

## Marcos verific\u00e1veis
- M1: Prot\u00f3tipo de pipeline pra 3 cen\u00e1rios (saud\u00e1vel, trinca, desalinhamento) funcionando.
- M2: Varredura param\u00e9trica conclu\u00edda e relat\u00f3rio preliminar de sensibilidade.
- M3: Valida\u00e7\u00e3o com pelo menos um conjunto de dados experimental da literatura.
- M4: Primeira vers\u00e3o do cap\u00edtulo de resultados pronta para revis\u00e3o do orientador.

## Forma de acompanhamento
- Relat\u00f3rios mensais com: simulacoes executadas, features extraidas, m\u00e9tricas (accuracy, recall, specificity), tempo de execu\u00e7\u00e3o.
- Reuni\u00f5es quinzenais com o orientador para feedback e ajustes no protocolo.
