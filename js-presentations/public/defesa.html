Análise de Espectros de Ordem Superior

Bi-espectro

Definido como:

B(f₁, f₂) = E[X(f₁)X(f₂)X*(f₁ + f₂)]

Características Extraídas

  • Magnitude máxima
  • Energia total
  • Entropia
  • Número de picos

Implementação

def calculate_bispectrum(signal, fs): segments = segment_signal(signal) bispectra = [] for segment in segments: X = fft(segment) bispectrum = np.outer(X, X) * np.conj(X) bispectra.append(bispectrum) return np.mean(bispectra, axis=0)
